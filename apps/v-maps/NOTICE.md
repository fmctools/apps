# Notice

- **V-maps began as Vela Nav**, the watch app by arunk140 in the CMF Tech Community apps repository (MIT). It has
  since been rewritten and extended by Abdalrahman (a new screen, map, marker, route dots, animation and icon) and
  is a separate app, `v-maps`, so it installs next to Vela Nav and never replaces it.
- **Fonts**: the glyph tables in `src/fonts.rs` are rendered from Noto Sans (SIL Open Font License 1.1), see
  `fonts/OFL.txt`.
- **Vela for Android** (arunk140/esp32-vela, GPL-3.0) is a separate program that V-maps talks to over Bluetooth. No
  code from it is in this app.
